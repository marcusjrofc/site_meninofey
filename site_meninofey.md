# Menino Fey - Linha Capilar ✂️⚽

Landing page desenvolvida para a marca paródia "Menino Fey", trazendo a melhor linha de cuidados capilares para garantir a sua "Definição de Meme" no dia a dia. Projeto focado em performance, interatividade e fidelidade à identidade visual da marca.

## 🚀 Funcionalidades

- **Design Responsivo e Fluido:** Layout perfeitamente adaptado para Desktop, Tablets e Mobile.
- **Carrossel Mobile Magnético:** Cards de produtos e vídeos com efeito *swipe* (arraste horizontal) nativo e suave em dispositivos móveis.
- **Renderização Dinâmica:** Produtos e vídeos são injetados na tela através de JavaScript, facilitando a manutenção e a adição de novos itens no futuro.
- **Modal Interativo ("Botão Secreto"):** Pop-up acionado pelo cabeçalho que exibe uma imagem surpresa em tela cheia (com efeito suave de escurecimento de fundo e zoom).
- **Identidade Visual Rigorosa:** Aplicação precisa das cores oficiais (Azul Royal `#0077B6` e Laranja `#FF6B00`).

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e limpa.
- **CSS3:** Estilização avançada com Flexbox, Media Queries para responsividade e animações fluidas via `@keyframes`.
- **JavaScript (Vanilla):** Lógica modular para controle do Modal e renderização dinâmica baseada em arrays de dados.

## 📁 Estrutura de Arquivos

```text
/
├── index.html        # Estrutura principal da página
├── css/
│   └── style.css     # Estilos, variáveis e responsividade
├── js/
│   └── script.js     # Lógica de injeção de cards e eventos do Modal
└── imgs_videos/      # Assets visuais (imagens, vídeos e logos)
```

## 💻 Como executar o projeto

1. Faça o clone ou baixe os arquivos deste repositório.
2. Certifique-se de que os seus assets (imagens e vídeos) estão corretamente nomeados e posicionados na pasta `imgs_videos`.
3. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Google Chrome, Edge, Safari) ou utilize a extensão *Live Server* no VS Code para uma melhor experiência de desenvolvimento.
