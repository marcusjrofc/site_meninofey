# Menino Fey - Linha de Cuidados Capilar 🧴✨

Este é o repositório do site **Menino Fey**, uma landing page dedicada a uma linha de cuidados capilares focada em definição natural, hidratação profunda e movimento para deixar os cachos sempre no ponto certo.

🔗 **Acesse o site ao vivo:** [Site Menino Fey](https://marcusjrofc.github.io/site_meninofey/)

---

## 🎯 Sobre o Projeto

O objetivo deste projeto é ser a vitrine digital para a marca "Menino Fey". A página apresenta a identidade visual da marca, sua proposta de valor para cabelos cacheados e uma seção dedicada à exibição dos produtos (catálogo).

## 🚀 Funcionalidades

- **Apresentação da Marca:** Header com logo personalizado e banner principal com o slogan da marca.
- **Vitrine de Produtos:** Seção dedicada ("Nossos Produtos") para exibir os itens da linha capilar.
- **Interatividade:** Elementos ocultos/modais interativos (como o "Segredo Menino Fey").
- **Design Limpo:** Foco no conteúdo visual com imagens e vídeos dos produtos.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias essenciais de desenvolvimento web front-end:

- **HTML5:** Para a estruturação semântica da página.
- **CSS3:** Para a estilização, paleta de cores e layout do site.
- **JavaScript:** (Provavelmente utilizado para as interações dinâmicas, como botões de fechar e animações).
